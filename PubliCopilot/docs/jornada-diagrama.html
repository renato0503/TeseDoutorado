3. Módulo de Avaliação — Análise de Minutas

Fluxo desde a seleção de exemplo até o relatório de risco com explicações SHAP.

📋 Preparação

  1. Usuário acessa /modulo_avaliacao/
  2. Gate: verifica PubliAuth.isLogado()
  3. Se anônimo → login automático
  4. Se primeiroAcesso=true → abre Profile Modal
  5. Usuário seleciona exemplo (opcional)
  6. Ou cola texto próprio + informa valor

🔗 Chamada à API

  1. POST /api/analisar_minuta
  2. Header: Authorization: Bearer {token}
  3. Body: {texto, valor}
  4. Rate limit: 1000 req/min por UID
  5. Timeout: 120s
  6. Auditoria: evento avaliar_inicio em logs/

🧠 Pipeline ML (Cloud Function)

  1. extrair_clausulas() — 16 regex patterns
  2. detectar_lacunas() — heurística
  3. calcular_score() — 0 a 100
  4. detectar_anomalia() — Isolation Forest
  5. rf.predict_proba() — Random Forest
  6. explainer.shap_values() — SHAP

📤 Resposta e Telemetria

  1. Response: {score, risco,
    lacunas, clausulas,
    explicacoes, contrafactuais}
  2. Tela exibe relatório formatado
  3. registrarEvento('avaliar_sucesso')
  4. registrarEvento('avaliar_click') para cada clique
  5. Salvamento opcional em analises/{id}

6. API Flow — Análise de Minuta (detalhado)

Passo a passo de cada camada: browser → Firebase Auth → Cloud Function → Firestore.

┌─────────────────────────────────────────────────────────────────────────────────────────┐ │ NAVEGADOR CLOUD FUNCTION FIRESTORE └─────────────────────────────────────────────────────────────────────────────────────────┘
T+0msBrowser │ PubliAuth.getIdToken() T+50msBrowser ┼─▶ POST /api/analisar_minuta │ Authorization: Bearer {idToken} │ {texto: "...", valor: 50000} T+80msCF │ verify_id_token(token) → uid/email/claims T+90msCF │ Rate limit: 1000 req/min por UID T+100msCF │ extrair_clausulas(texto) → 16 padrões regex T+110msCF │ detectar_lacunas(texto) → lista lacunas T+115msCF │ calcular_score() → 0-100 T+120msCF │ Isolation Forest → anomaly_score T+130msCF │ Random Forest → rf_proba, rf_class T+140msCF │ SHAP shap_values() → top-3 features T+145msCF │ Contrafactuais jurídicos gerados T+150msCF │ Montando response JSON T+155msCF │ set(doc logs/{id}, {tipo:'analise', uid, email, orgaoId, duracao_ms, status:'sucesso'}) T+160msCF │ FirebaseAuth.write T+170msCF │◀─ ✓ logs gravado T+175msCF │──▶ HTTP 200 {score, risco, lacunas, clausulas, explicacoes, shap, contrafactuais} T+200msBrowser │ registrarEvento('avaliar_sucesso', {score, risco}) T+205msBrowser │ salvarGeracao() → Firestore editais/{id} T+210msBrowser │ UI atualiza: exibe score + risk badge

🔒 Regras de Segurança

/usuarios/{userId}
  read:  isOwner(userId) || isAdmin()
  create: isOwner(userId)
  update: isOwner(userId) || isAdmin()
  delete: isAdmin()

/orgaos/{orgaoId}
  read:  isAuthenticated()
  write: isAdmin()

/analises/{userId}/**
  read:  isOwner(userId) || isAdmin()
  create: isOwner(userId)
  delete: isAdmin()

/editais/{editalId}
  read:  isAuthenticated()
  create: isOwner(request.resource.data.usuarioId)
  update/delete: isOwner(resource.data.usuarioId) || isAdmin()

/logs/{logId}
  read:  isAdmin()
  create: isAuthenticated()
  update/delete: never

📊 Índices Compostos

Collection: analises
  fields: orgaoId ASC + dataCriacao DESC
  fields: uid ASC + dataCriacao DESC

Collection: editais
  fields: orgaoId ASC + dataCriacao DESC
  fields: usuarioId ASC + dataCriacao DESC

Collection: logs
  fields: orgaoId ASC + timestamp DESC
  fields: uid ASC + timestamp DESC
  fields: tipo ASC + timestamp DESC
